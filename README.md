# CNN-Based Criminal Facial Recognition System

A deep learning-based Criminal Facial Recognition System built using **InceptionV3 CNN**, **Flask**, **OpenCV**, and **Machine Learning** to identify individuals from uploaded facial images.

## Features

* Criminal Face Detection using OpenCV
* Facial Recognition using InceptionV3 CNN
* Deep Learning Model Training
* Criminal Information Display
* Confidence Score Prediction
* Professional Web Interface
* Unknown Person Detection

## Tech Stack

* Python
* Flask
* TensorFlow / Keras
* OpenCV
* InceptionV3
* HTML / CSS

## Project Workflow

Image Upload
↓
Face Detection (OpenCV)
↓
Image Preprocessing
↓
InceptionV3 CNN Model
↓
Person Classification
↓
Criminal Details Display
